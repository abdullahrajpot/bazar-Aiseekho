Import rules from firebase/database.rules.json in Firebase Console → Realtime Database → Rules.

Or merge these indexOn entries into your existing rules:

  "crisis_events": {
    ".indexOn": ["detectedAt", "status", "areaKey"]
  },
  "action_log": {
    ".indexOn": ["timestamp", "crisisId", "agent"]
  },
  "agent_log": {
    ".indexOn": ["timestamp", "agent", "severity"]
  },
  "truth_feed": {
    ".indexOn": ["timestamp", "area"]
  },
  "user_crisis_reports": {
    ".indexOn": ["timestamp", "area"]
  }

This removes Firebase warnings when the app queries:
- crisis_events ordered by detectedAt
- action_log ordered by timestamp

Publish rules, then restart the app.
